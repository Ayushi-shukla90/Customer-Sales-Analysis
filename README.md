🛍️ Customer Sales Analysis Project
📌 Introduction

The Customer Sales Analysis Project is a comprehensive data analytics project designed to explore customer purchasing behavior, product trends, seasonal demand, and sales performance using transactional shopping data.

This project aims to help businesses better understand their customers by analyzing demographic information, shopping habits, payment preferences, promotional effectiveness, and overall purchasing trends. Through exploratory data analysis (EDA), statistical insights, and visualizations, the project uncovers actionable business intelligence that can support strategic decision-making.

The dataset contains detailed customer transaction records including age, gender, purchased products, purchase amounts, payment methods, shipping preferences, review ratings, and purchasing frequency.

🎯 Project Goals

The main objectives of this project are:

Understand customer buying behavior
Identify top-performing products and categories
Analyze seasonal shopping patterns
Discover customer spending trends
Evaluate the effectiveness of discounts and promo codes
Examine shipping and payment preferences
Analyze customer loyalty and repeat purchases
Generate business insights using data visualization
